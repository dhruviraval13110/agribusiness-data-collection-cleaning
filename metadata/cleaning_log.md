# Cleaning Log

## Purpose

This file records the main data-cleaning steps used in the project.

## Planned Cleaning Steps

1. Inspect the raw dataset.
2. Check column names and data types.
3. Check missing values.
4. Check duplicate records.
5. Standardize crop names.
6. Standardize location names.
7. Verify units.
8. Check dates and seasons.
9. Investigate unusual values.
10. Run final quality checks.

## Important Note

Unusual values will not be removed automatically. They will first be checked against the original source and the agricultural context.
